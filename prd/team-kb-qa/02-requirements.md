# 核心需求

## 团队管理员

- 支持配置多个知识库路径。
- 支持知识库命名。
- 支持启用 / 停用知识库。
- 支持查看知识库索引状态。
- 支持切换内置大模型。
- 支持配置自定义模型。
- 支持切换 Agent。
- 当前先支持 OpenAI Agent。
- 后续预留 Claude Code Agent。
- 支持管理普通用户。
- 支持查看用户信息、状态、用量。
- 支持仪表盘监控。

## 普通用户

- 支持选择有权限访问的知识库。
- 支持知识库问答。
- 支持多轮会话。
- 支持会话新建、切换、重命名、删除。
- 支持查看自己的历史会话。
- 不允许查看其他用户的历史会话。

## 系统能力

- 支持多知识库。
- 支持多用户。
- 支持用户会话隔离。
- 支持模型配置。
- 支持 Agent 配置。
- 支持用量统计。
- 支持基础运行监控。
- 回答尽量展示知识来源。

## 第一阶段优先级

P0：

- 登录 / 用户识别。
- 多知识库配置。
- 普通用户问答页。
- 用户会话隔离。
- 管理员用户管理。
- 管理员模型配置。

P1：

- Agent 配置。
- 仪表盘。
- 用量统计。
- 知识库索引状态。

P2：

- 用户组。
- 复杂权限。
- 审计日志。
- 外部数据源。
- SSO。
