# team-kb-qa

需求简称：团队知识库问答。

这个目录用于记录 `Team Wiki` 从后端验证页面升级为团队可用产品的需求规划。

文件说明：

- `01-purpose.md`：产品目的和定位。
- `02-requirements.md`：核心需求清单。
- `03-versions.md`：后续版本记录。
- `04-design-proposal.md`：现代 AI 知识工作台设计方案。

后续如果有新版本，直接在本目录新增文件，例如：

- `v0.3-react-shell.md`
- `v0.4-user-chat.md`
- `v0.5-admin-console.md`
