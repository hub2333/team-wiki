# 系统架构设计

## 整体架构

系统采用 **分层架构**，分为三层：

1. **数据层** — Markdown 文档仓库，存储所有原始知识
2. **索引层** — MetadataCache 引擎，解析文档并构建知识图谱
3. **接口层** — MCP 协议对外暴露，支持 AI 工具调用

## 技术栈

- **运行环境**: Node.js TypeScript
- **知识图谱**: 自定义 MetadataCache 引擎
- **搜索**: MiniSearch 全文搜索
- **AI 集成**: OpenAI Agents SDK / DeepSeek
