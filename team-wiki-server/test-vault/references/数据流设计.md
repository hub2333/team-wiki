# 数据流设计

## 数据流向

```
Codex 分析源码 → 生成 Markdown 文档
    ↓
Git Push → 服务器 Git Pull
    ↓
VaultWatcher 检测文件变更
    ↓
Parser 解析文档 → MetadataCache 更新 → 知识图谱构建
    ↓
MCP Server 对外暴露 ← AI Agent 调用
```

## 核心流程

1. **文档生成**: Codex 分析源代码，生成结构化的 Markdown 文档
2. **同步**: 通过 Git 推送到服务器
3. **索引**: 服务器自动检测变更，增量更新图谱
4. **查询**: 用户通过 MCP 或 Chat 界面检索知识
