# 部署指南

## 快速启动

```bash
git clone https://github.com/example/knowledge-base
cd knowledge-base

# 安装依赖
npm install

# 设置 API Key（DeepSeek）
export DEEPSEEK_API_KEY=sk-xxxxx

# 启动服务
VAULT_PATH=./docs npm start
```

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| VAULT_PATH | ./vault | 文档目录 |
| PORT | 3100 | 服务端口 |
| DEEPSEEK_API_KEY | - | DeepSeek API Key |
